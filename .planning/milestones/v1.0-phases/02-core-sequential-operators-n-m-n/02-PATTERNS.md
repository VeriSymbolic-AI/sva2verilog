### 1. `templates/concat_delay.sv.j2` (CREATE)

**Role:** Jinja2 template for the unified delay counter module (`##N` and `##[M:N]`).

**Closest analog:** `templates/bool_expr.sv.j2`

**Structural pattern to follow (from `bool_expr.sv.j2`):**
```jinja2
// Generated by sva2rtl {{ sva2rtl_version }}
// Source: {{ source_loc }}
// Original property: @({{ clock_edge }} {{ clock_signal }}) {{ original_text }}
module {{ module_name }} (
    input  logic {{ clock_signal }},
    input  logic rst_n,
    input  logic start,
{# ... signal ports ... #}
    output logic active,
    output logic pass,
    output logic fail,
    output logic attempt_fired
);
    // ... registered logic ...
    always_ff @({{ clock_edge }} {{ clock_signal }}) begin
        if (!rst_n) begin
            // sync reset all regs to zero
        end else begin
            // operational logic
        end
    end
    // assign outputs from _q registers
endmodule
```

**New elements unique to this template:**
- `parameter` declarations: counter width derived from `$clog2(delay_max + 1)`
- Counter register: `logic [CNT_WIDTH-1:0] count_q;`
- Window comparator: `(count_q >= M) && (count_q <= N)` — synthesizer optimizes when M==N
- Counter increments on each cycle while active, resets on `start` pulse
- `pass` output HIGH for the entire M..N window (D-03)
- `active` output HIGH from `start` until count reaches N

**Template parameters expected (from `params` dict):**
- `module_name` — e.g. `"sva_delay_2_5"`
- `clock_signal`, `clock_edge` — clocking
- `delay_min`, `delay_max` — integer values (string-encoded for Jinja2)
- `cnt_width` — counter bit-width (pre-computed by composer)
- `source_loc`, `sva2rtl_version`, `original_text` — standard header params

### 2. `templates/overlap_bitvec.sv.j2` (CREATE)

**Role:** Jinja2 template for overlapping implication (`|->`) with bit-vector thread tracking.

**Closest analog:** `templates/bool_expr.sv.j2`

**Structural pattern to follow:** Same module skeleton (header comment, port list, `always_ff`, registered outputs).

**New elements unique to this template:**
- `parameter BV_WIDTH = <N>` — user-tunable bit-vector width (D-06)
- Bit-vector register: `logic [BV_WIDTH-1:0] bv_q;` — tracks concurrent threads
- Shift + insert logic: on antecedent match, set a bit; shift each cycle
- Overflow detection: all bits occupied + new antecedent match → `fail` + `overflow_flag` latch (D-05)
- Halt state: once `overflow_flag` is set, freeze bv_q, gate all outputs to 0 (D-05)
- `overflow_flag` output: sticky, only cleared by `rst_n` (D-07)
- Sub-module instantiation ports: `ant_pass` (from antecedent), `con_pass` (from consequent)
- Token-passing wiring: antecedent `pass` → delay `start`; delay `pass` → consequent `start`

**Template parameters expected:**
- `module_name`, `clock_signal`, `clock_edge` — standard
- `bv_width` — bit-vector width (string-encoded integer)
- `source_loc`, `sva2rtl_version`, `original_text` — standard header
- `children` — list of child instantiation dicts (for sub-module wiring)

### 3. `templates/nonoverlap.sv.j2` (CREATE)

**Role:** Jinja2 template for non-overlapping implication (`|=>`). Structurally identical to `overlap_bitvec.sv.j2` but with a 1-cycle delay inserted between antecedent match and consequent evaluation start.

**Closest analog:** `templates/overlap_bitvec.sv.j2` (sibling)

**Key difference from overlap:** The antecedent `pass` goes through a 1-cycle register before starting the consequent. This can be implemented as:
- Instantiation of a `concat_delay` child with `delay_min=1, delay_max=1` between antecedent and consequent, OR
- Inline 1-cycle pipeline register within the template itself

**Decision D-08/D-09** favors the sub-module approach: `|=>` is equivalent to `|-> ##1`, so the template instantiates an implicit delay child.

```python
def _compose_seq_concat(
    node: SeqConcat, clock: ClockSpec, label: str | None, original_text: str
) -> CheckerNode:
    module_name = module_name_from_label(label, original_text)
    children: list[CheckerNode] = []

    # Each element becomes a bool_expr child; each delay becomes a concat_delay child
    for i, elem in enumerate(node.elements):
        elem_checker = compose(elem, clock, None, original_text)
        children.append(elem_checker)
        if i < len(node.delays):
            delay_min, delay_max = node.delays[i]
            delay_checker = _make_delay_node(delay_min, delay_max, clock, node.source_loc)
            children.append(delay_checker)

    # Collect all observed signals from children
    all_signals = _collect_signals(children)

    params: dict[str, str] = {
        "module_name": module_name,
        "clock_signal": clock.signal,
        "clock_edge": clock.edge,
        "source_loc": str(node.source_loc),
        "sva2rtl_version": __version__,
        "original_text": original_text,
    }
    return CheckerNode(
        template_name="concat_delay",  # top-level wrapper for delay chain
        module_name=module_name,
        params=params,
        observed_signals=all_signals,
        source_loc=node.source_loc,
        children=tuple(children),
    )
```

```python
import math

def _make_delay_node(
    delay_min: int, delay_max: int, clock: ClockSpec, source_loc: SourceLoc
) -> CheckerNode:
    cnt_width = max(1, math.ceil(math.log2(delay_max + 1))) if delay_max > 0 else 1
    mod_name = f"sva_delay_{delay_min}_{delay_max}"
    params: dict[str, str] = {
        "module_name": mod_name,
        "delay_min": str(delay_min),
        "delay_max": str(delay_max),
        "cnt_width": str(cnt_width),
        "clock_signal": clock.signal,
        "clock_edge": clock.edge,
        "source_loc": str(source_loc),
        "sva2rtl_version": __version__,
        "original_text": f"##{delay_min}" if delay_min == delay_max else f"##[{delay_min}:{delay_max}]",
    }
    return CheckerNode(
        template_name="concat_delay",
        module_name=mod_name,
        params=params,
        observed_signals=(),
        source_loc=source_loc,
        children=(),
    )
```

```python
def _compose_implication(
    node: PropImplication, clock: ClockSpec, label: str | None, original_text: str
) -> CheckerNode:
    module_name = module_name_from_label(label, original_text)
    ant_checker = compose(node.antecedent, clock, None, original_text)
    con_checker = compose(node.consequent, clock, None, original_text)

    template = "overlap_bitvec" if node.overlapping else "nonoverlap"
    # BV_WIDTH auto-determined from consequent max length (default heuristic)
    bv_width = _estimate_bv_width(node.consequent)

    params: dict[str, str] = {
        "module_name": module_name,
        "bv_width": str(bv_width),
        "clock_signal": clock.signal,
        "clock_edge": clock.edge,
        "source_loc": str(node.source_loc),
        "sva2rtl_version": __version__,
        "original_text": original_text,
    }
    all_signals = _collect_signals([ant_checker, con_checker])

    return CheckerNode(
        template_name=template,
        module_name=module_name,
        params=params,
        observed_signals=all_signals,
        source_loc=node.source_loc,
        children=(ant_checker, con_checker),
    )
```

**Pattern: `extract_signals()` reuse — called on leaf `BoolExpr` nodes. A new `_collect_signals()` helper deduplicates across children:**
```python
def _collect_signals(children: list[CheckerNode]) -> tuple[tuple[str, str], ...]:
    """Collect and deduplicate observed_signals from all children."""
    seen: dict[str, str] = {}
    for child in children:
        for port_name, sig_name in child.observed_signals:
            if port_name not in seen:
                seen[port_name] = sig_name
    return tuple((k, v) for k, v in seen.items())
```

```python
def emit_all(checker: CheckerNode, template_dir: Path | None = None) -> dict[str, str]:
    """Recursively emit all modules in the CheckerNode tree.

    Returns dict mapping module_name → rendered SV text. Each unique
    module_name appears exactly once (enables CSE deduplication).
    """
    env = _make_env(template_dir)
    results: dict[str, str] = {}
    _emit_recursive(checker, env, results)
    return results


def _emit_recursive(
    checker: CheckerNode, env: Environment, results: dict[str, str]
) -> None:
    """Depth-first emit: children first, then parent."""
    # Emit children (sub-modules) before parent
    for child in checker.children:
        if child.module_name not in results:
            _emit_recursive(child, env, results)

    # Emit this node
    if checker.module_name not in results:
        template_file = checker.template_name + ".sv.j2"
        tmpl = env.get_template(template_file)
        ctx: dict[str, object] = dict(checker.params)
        ctx["observed_signals"] = checker.observed_signals
        ctx["children"] = checker.children  # available to template for instantiation
        results[checker.module_name] = str(tmpl.render(**ctx))
```

## Risk Patterns (from existing code)

1. **`_check_unsupported()` gate:** Currently blocks `SequenceConcat` at line 227. Must be removed/bypassed BEFORE new dispatch logic can execute. Order matters.
