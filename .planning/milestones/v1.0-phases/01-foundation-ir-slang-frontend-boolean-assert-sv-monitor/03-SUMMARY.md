# Plan 03 Summary: Template Emitter + bool_expr Template

## What Was Built

### Task 1 — `src/sva2rtl/composer.py`

SVA IR → CheckerNode transformer. Three public functions:

- **`module_name_from_label(label, property_text)`** — `sva_{label}` when label is provided (non-alphanum chars sanitized to `_`); `sva_prop_{sha256[:8]}` (deterministic hash) when label is `None`.
- **`extract_signals(expr_text)`** — regex `\b([a-zA-Z_][a-zA-Z0-9_]*)\b` filtered against a comprehensive IEEE 1800-2017 keyword frozenset; returns `(port_name, signal_name)` pairs in first-seen order with deduplication.
- **`compose(node, clock, label, original_text)`** — maps `BoolExpr` → `CheckerNode` populating `template_name`, `module_name`, `params`, `observed_signals`, and `source_loc`. Raises `UnsupportedConstruct` (with node's `source_loc`) for all non-`BoolExpr` IR node types.

### Task 2 — `templates/bool_expr.sv.j2`

Jinja2 template producing a complete, standalone SystemVerilog monitor module:

- **3-line header comment**: `Generated by`, `Source:`, `Original property:`
- **Port list**: `clk` (named from `clock_signal`), `rst_n`, `start`, one `input logic` per observed signal (loop), then `active`/`pass`/`fail`/`attempt_fired` outputs.
- **Combinational stage**: `assign bool_result = ({{ bool_expr }});`
- **`always_ff` block**: synchronous reset clearing all `_q` registers to `1'b0`; active logic: `active_q <= start`, `pass_q <= start & bool_result`, `fail_q <= start & ~bool_result`, `attempt_fired_q <= attempt_fired_q | start` (sticky — prevents P1.1 vacuous satisfaction).
- **Continuous assigns** for all four output ports.
- `trim_blocks=True, lstrip_blocks=True` ensure the signal-port loop emits no spurious blank lines.

### Task 3 — `src/sva2rtl/emitter.py`

Jinja2 rendering engine:

- **`_get_template_dir()`** — resolves `<repo_root>/templates/` via `Path(__file__).parent.parent.parent`; falls back to `Path(__file__).parent / "templates"` for installed packages.
- **`_make_env(template_dir)`** — `FileSystemLoader`, `trim_blocks=True`, `lstrip_blocks=True`, `keep_trailing_newline=True`, `autoescape=False`.
- **`emit(checker, template_dir)`** — builds render context from `checker.params` (str dict) plus `observed_signals` (tuple), renders `checker.template_name + ".sv.j2"`.
- **`write_output(sv_text, output_path)`** — writes to file (creating parent dirs) or stdout when `output_path is None`.

### Task 4 — Golden Files + Unit Tests

**Golden files** (`tests/golden/`):
- `bool_labeled.sv` — `sva_my_check` (from label `"my_check"`), signals `a, b`.
- `bool_simple.sv` — `sva_prop_06c5ed75` (sha256 of `"(a && b)"`), signals `a, b`.
Both are complete, compilable SV; used as regression anchors for all future template changes.

**`tests/test_composer.py`** (26 tests):
- `module_name_from_label`: label with special chars sanitization, pattern match, determinism, differing texts, empty label.
- `extract_signals`: simple extraction, keyword exclusion, dedup, port==signal, order, empty expr, single signal.
- `compose`: returns `CheckerNode`, correct `template_name`/`module_name`/`params`, all required params present, signal extraction, `source_loc` threading, no children, `UnsupportedConstruct` for `SeqConcat` with source_loc carried through.

**`tests/test_emitter.py`** (18 tests):
- Structural: module name, `if (!rst_n)`, bool expr text, all 4 output ports, `always_ff`, sticky `attempt_fired`, `endmodule`, observed signal input ports, version comment, source-loc comment, trailing newline, negedge clock.
- Golden match: `test_emit_golden_match` compares line-by-line (trailing whitespace stripped) against `bool_labeled.sv`.
- I/O: `write_output` to file (creates parent dirs), `write_output` to stdout.

## Notes

- **Double parens** in `assign bool_result = ((a && b))`: expected — `BoolExpr.text` already contains parens from `expr_to_sv` in the AST importer; the template wraps it in one additional pair for safety. Not a bug.
- **`attempt_fired` design**: sticky OR (`attempt_fired_q <= attempt_fired_q | start`) ensures any system reading `pass=0, fail=0` cannot confuse "nothing checked yet" with "all checks passed". This is first-class from Phase 1 and cannot be retrofitted later.
- **Phase 1.4 (CLI)** is now unblocked: `compose()` and `emit()` are the two functions the CLI calls to complete the end-to-end pipeline.
