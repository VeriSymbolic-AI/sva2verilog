# Plan 03: Template Emitter + bool_expr Template

<objective>
Implement the composer (SVA IR -> CheckerNode) and emitter (CheckerNode -> SystemVerilog text via Jinja2), along with the bool_expr.sv.j2 template. After this plan, a BoolExpr IR node can be transformed into a complete, compilable SystemVerilog monitor module with the standard port interface, registered outputs, synchronous reset, and proper header comments.
</objective>

<threat_model>
- **Template injection:** Jinja2 templates render user-derived strings (signal names, module names). Signal names come from slang (already validated SV identifiers). Module names are sanitized via regex. No `| safe` filter on user input without sanitization.
- **File I/O:** Emitter writes output to a specified path. Path is user-controlled via CLI `--output` flag. No path traversal concern since we write exactly one file to the exact path specified.
- **No network/subprocess:** This plan uses no external processes.
</threat_model>

## Task 1: Implement composer.py — SVA IR to CheckerNode

<read_first>
- src/sva2rtl/ir.py (BoolExpr, CheckerNode, ClockSpec, SourceLoc classes)
- .planning/phases/01-foundation-ir-slang-frontend-boolean-assert-sv-monitor/01-RESEARCH.md (Research Q4: module naming, Research Q5: token-passing for boolean)
</read_first>

<action>
Create `src/sva2rtl/composer.py` with:

1. `compose(node: SVANode, clock: ClockSpec, label: str | None, original_text: str) -> CheckerNode`
   - For `BoolExpr` nodes: creates a `CheckerNode` with:
     - `template_name = "bool_expr"`
     - `module_name = module_name_from_label(label, node.text)`
     - `params` containing keys: "bool_expr", "clock_signal", "clock_edge", "module_name", "source_loc", "sva2rtl_version", "original_text"
     - `observed_signals` extracted from `node.text` (parse signal names from expression)
     - `source_loc` from node
     - `children = ()`
   - For non-BoolExpr nodes: raise `UnsupportedConstruct`

2. `module_name_from_label(label: str | None, property_text: str) -> str`
   - If label is not None: `re.sub(r'[^a-zA-Z0-9_]', '_', label)` -> return `f"sva_{safe}"`
   - If label is None: `hashlib.sha256(property_text.encode()).hexdigest()[:8]` -> return `f"sva_prop_{h}"`

3. `extract_signals(expr_text: str) -> tuple[tuple[str, str], ...]`
   - Simple regex-based extraction of identifiers from the boolean expression text
   - Pattern: `r'\b([a-zA-Z_][a-zA-Z0-9_]*)\b'` excluding SV keywords
   - Returns tuple of `(signal_name, signal_name)` pairs (port_name == signal_name for Phase 1)
   - Exclude known non-signal tokens: numeric literals, operators
</action>

<acceptance_criteria>
- `src/sva2rtl/composer.py` exports `compose` and `module_name_from_label` functions
- `module_name_from_label("my_check", "a && b")` returns `"sva_my_check"`
- `module_name_from_label(None, "a && b")` returns a string matching pattern `sva_prop_[0-9a-f]{8}`
- `compose(BoolExpr(text="(a && b)", source_loc=...), clock, "my_check", "a && b")` returns a `CheckerNode` with `template_name="bool_expr"` and `module_name="sva_my_check"`
- CheckerNode.params contains key "bool_expr" with value "(a && b)"
- CheckerNode.params contains key "clock_edge" with value "posedge"
- CheckerNode.observed_signals contains tuples with "a" and "b" as signal names
- Passing a `SeqConcat` node to `compose` raises `UnsupportedConstruct`
- `uv run mypy src/sva2rtl/composer.py --strict` reports zero errors
</acceptance_criteria>

## Task 2: Create templates/bool_expr.sv.j2

<read_first>
- .planning/phases/01-foundation-ir-slang-frontend-boolean-assert-sv-monitor/01-RESEARCH.md (Research Q3: complete template with variables table)
</read_first>

<action>
Create directory `templates/` at project root. Create `templates/bool_expr.sv.j2` with the boolean assertion monitor template:

- Header comment block: `// Generated by sva2rtl {{ sva2rtl_version }}`, `// Source: {{ source_loc }}`, `// Original property: @({{ clock_edge }} {{ clock_signal }}) {{ original_text }}`
- Module declaration: `module {{ module_name }} (` with standard ports
- Input ports: `clk` (named from `clock_signal`), `rst_n`, `start`, then one `input logic` per observed signal
- Output ports: `active`, `pass`, `fail`, `attempt_fired` (`pass` is a valid SystemVerilog port identifier per IEEE 1800 — use it as specified in OUT-01)
- Combinational: `logic bool_result; assign bool_result = ({{ bool_expr }});`
- Registered outputs in `always_ff @({{ clock_edge }} {{ clock_signal }})` block with `if (!rst_n)` synchronous reset to 0
- Logic: `active_q <= start`, `pass_q <= start & bool_result`, `fail_q <= start & ~bool_result`, `attempt_fired_q <= attempt_fired_q | start`
- Continuous assigns: `active = active_q`, `pass = pass_q`, `fail = fail_q`, `attempt_fired = attempt_fired_q`
- `endmodule`

Use Jinja2 `{% for %}` loop for observed signal input ports. Use `trim_blocks` and `lstrip_blocks` compatible formatting.
</action>

<acceptance_criteria>
- `templates/bool_expr.sv.j2` exists and is valid Jinja2 syntax
- Template contains `module {{ module_name }}` declaration
- Template contains `always_ff @({{ clock_edge }} {{ clock_signal }})` block
- Template contains `if (!rst_n)` synchronous reset clause
- Template contains `assign bool_result = ({{ bool_expr }});`
- Template outputs include: `active`, `pass`, `fail`, `attempt_fired`
- All four output registers reset to `1'b0`
- `attempt_fired_q` uses sticky OR: `attempt_fired_q | start`
- Header comment includes `{{ original_text }}`
</acceptance_criteria>

## Task 3: Implement emitter.py — Jinja2 rendering engine

<read_first>
- src/sva2rtl/ir.py (CheckerNode class)
- templates/bool_expr.sv.j2 (the template to render)
- .planning/phases/01-foundation-ir-slang-frontend-boolean-assert-sv-monitor/01-RESEARCH.md (Research Q8: template loading pattern)
</read_first>

<action>
Create `src/sva2rtl/emitter.py` with:

1. `emit(checker: CheckerNode) -> str`
   - Loads Jinja2 environment with `FileSystemLoader` pointing to `templates/` directory
   - Sets `trim_blocks=True`, `lstrip_blocks=True`
   - Renders `checker.template_name + ".sv.j2"` with `checker.params` as template variables
   - Additionally passes `observed_signals=checker.observed_signals` to template
   - Returns rendered string

2. `_get_template_dir() -> Path`
   - Returns `Path(__file__).parent.parent.parent / "templates"` (project root templates/)
   - Falls back: checks if templates are installed as package data

3. `write_output(sv_text: str, output_path: Path | None) -> None`
   - If `output_path` is None: print to stdout
   - If `output_path` is provided: write to file with newline at end

Imports: `jinja2` (Environment, FileSystemLoader), `pathlib.Path`, `sva2rtl.ir.CheckerNode`
</action>

<acceptance_criteria>
- `src/sva2rtl/emitter.py` exports `emit` and `write_output` functions
- `emit(checker_node)` returns a non-empty string containing `module sva_my_check`
- Rendered output contains `always_ff @(posedge clk)` (for posedge clock)
- Rendered output contains `assign bool_result = (` followed by the boolean expression
- Rendered output contains `// Generated by sva2rtl`
- Rendered output ends with `endmodule\n`
- `write_output(text, Path("/tmp/test.sv"))` creates the file with correct content
- `uv run mypy src/sva2rtl/emitter.py --strict` reports zero errors
