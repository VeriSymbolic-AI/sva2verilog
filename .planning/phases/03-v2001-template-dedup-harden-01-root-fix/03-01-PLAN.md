# Plan 01: Create Shared Macros + Migrate Simple Templates (Wave 1)

## Goal

Create shared Jinja2 macro files (`_macros.sv.j2`, `_attempt_fired_macro.sv.j2`) and migrate the 5 simple templates (bool_expr, rose, fell, stable, past) to use them. Verify SV golden output is byte-identical and V2001 golden parity passes before proceeding to Wave 2.

## Requirements

- **REFACTOR-01** — Always-block bodies live in macros; both SV/V2001 branches call them
- **REFACTOR-02** — HARDEN-01 fix at macro root, verified in both output modes
- **HARDEN-01** — `attempt_fired_q` correctly latched, not cleared by `disable_i`

<action>
Create `templates/_macros.sv.j2` with three macros:

1. **`signal_type(verilog_mode)`**: Returns `"reg"` for true, `"logic"` for false. Used for internal signal declarations. Also a **`port_type(verilog_mode, direction, name)`** variant that emits `direction name` for V2001 and `direction logic name` for SV — handles port list dedup.

2. **`always_block_header(verilog_mode, clock_edge, clock_signal)`**: Returns `"always @({{ clock_edge }} {{ clock_signal }})"` for V2001, `"always_ff @({{ clock_edge }} {{ clock_signal }})"` for SV.

3. **`zero_literal(verilog_mode)`**: Returns `"0"` for V2001, `"'0"` for SV.

Macros use `with context` to access caller's template variables (verilog_mode, clock_edge, clock_signal).

Acceptance: Template renders without error when imported by bool_expr.sv.j2.
</action>

<task id="3.1.2">
<title>Create templates/_attempt_fired_macro.sv.j2 with HARDEN-01 fix</title>
<read_first>
- templates/bool_expr.sv.j2 (current attempt_fired_q pattern: cleared by !rst_n || disable_i)
- .planning/phases/03-v2001-template-dedup-harden-01-root-fix/03-CONTEXT.md (detailed fix design)
</read_first>
<action>
Create `templates/_attempt_fired_macro.sv.j2` with a single macro `attempt_fired_logic(verilog_mode, clock_edge, clock_signal, trigger_signal, zero_literal)`:

```
{% macro attempt_fired_logic(verilog_mode, clock_edge, clock_signal, trigger_signal, zero_literal) %}
{% from '_macros.sv.j2' import always_block_header with context %}
{{ always_block_header(verilog_mode, clock_edge, clock_signal) }}
    if (!rst_n) begin
        attempt_fired_q <= {{ zero_literal }};
    end else if ({{ trigger_signal }}) begin
        attempt_fired_q <= 1'b1;  // sticky — never cleared by disable_i
    end
end
{% endmacro %}
```

- `trigger_signal` is `"start"` for simple templates, `"ant_pass_w"` for bit-vector templates (Plan 02)
- This macro emits a standalone always block — it does NOT share the main always block
- The `disable_i` signal is intentionally absent from the reset condition
</action>
<acceptance_criteria>
- `test -f templates/_attempt_fired_macro.sv.j2` succeeds
- `grep -q 'if (!rst_n)' templates/_attempt_fired_macro.sv.j2` succeeds
- `grep -v 'disable_i' templates/_attempt_fired_macro.sv.j2` — confirms disable_i is NOT in the reset condition
- `grep -q 'sticky' templates/_attempt_fired_macro.sv.j2` succeeds
</acceptance_criteria>
</task>
