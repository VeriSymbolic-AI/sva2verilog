# Plan 07-01: v1.1.0 Release

## Overview

Single plan for the final v1.1.0 release. Tasks run sequentially: smoke test → release notes → tag.

No production code changes. This is pure release ceremony.

## Threat Model

| Threat | Mitigation |
|--------|-----------|
| Tag on broken commit | Smoke test before tag |
| Release notes incomplete | Checklist against all 6 phases |
| Wrong version in tag | Verify `__version__` and `pyproject.toml` first |
