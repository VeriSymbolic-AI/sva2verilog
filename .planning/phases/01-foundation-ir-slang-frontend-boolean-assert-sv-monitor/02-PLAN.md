# Plan 02: Slang Frontend + AST Importer

<objective>
Implement the slang subprocess invocation (frontend.py) and the JSON AST to SVA IR translation (ast_importer.py). After this plan, a slang JSON AST dict can be transformed into a BoolExpr IR node with correct ClockSpec and SourceLoc. Unsupported SVA constructs are detected and rejected with source-location-annotated errors.
</objective>

<threat_model>
- **Subprocess execution:** `frontend.py` runs `slang` as a subprocess. Mitigated by: validating `slang_path` is a simple binary name or existing path; capturing stderr; using `timeout=60` to prevent hangs; never passing user input as shell arguments (use list form of subprocess.run).
- **File I/O:** Writes a temp JSON file for slang output; reads it back. Uses `tempfile.NamedTemporaryFile` with proper cleanup.
- **Untrusted JSON:** slang JSON is trusted (generated by our own subprocess), but we still validate expected top-level structure before dispatch.
</threat_model>

<action>
Create `src/sva2rtl/frontend.py` with function `invoke_slang(sv_file: Path, slang_path: str = "slang") -> dict`:

1. Create a temporary file path for JSON output using `tempfile.NamedTemporaryFile(suffix=".json", delete=False)`
2. Run subprocess: `[slang_path, "--ast-json", str(tmp_json_path), "--ast-json-source-info", str(sv_file)]`
3. Catch `FileNotFoundError` -> raise `SlangNotFound(message=f"slang not found at '{slang_path}'.\nInstall: https://github.com/MikePopoloski/slang/releases\nOr pass: --slang-path /path/to/slang")`
4. Check `result.returncode != 0` -> raise `SvaCompileError(message=f"slang failed (exit {result.returncode}):\n{result.stderr}")`
5. Read the JSON file (not stdout — Research Q1 finding about non-JSON prefixes on stdout)
6. Parse with `json.loads()` and return the dict
7. Clean up temp file in a `finally` block

Import `subprocess`, `json`, `tempfile`, `Path` from pathlib, error classes from `sva2rtl.errors`.
</action>

## Task 3: Implement ast_importer.py — JSON to SVA IR

<read_first>
- src/sva2rtl/ir.py (BoolExpr, ClockSpec, SourceLoc, SVANode classes)
- src/sva2rtl/errors.py (UnsupportedConstruct class)
- .planning/phases/01-foundation-ir-slang-frontend-boolean-assert-sv-monitor/01-RESEARCH.md (Research Q1: node kinds, Research Q6: expr_to_sv implementation)
- tests/fixtures/bool_simple.json (the structure being parsed)
</read_first>

<action>
Create `src/sva2rtl/ast_importer.py` with:

1. `import_assertion(ast: dict) -> tuple[SVANode, ClockSpec, str, str | None]`
   - Returns: (ir_node, clock_spec, original_sva_text, label_or_None)
   - Walks `ast["design"]["members"]` to find `ConcurrentAssertion` nodes
   - Extracts `PropertySpec.clocking` -> `ClockSpec` (edge from `SignalEvent.edge`, signal from `NamedValue.symbol.split(" ", 1)[-1]`)
   - Dispatches on `PropertySpec.expr.kind` to build IR

2. `expr_to_sv(node: dict) -> str`
   - Recursive function mapping JSON expression nodes to SV text strings
   - `NamedValue` -> `node["symbol"].split(" ", 1)[-1]`
   - `BinaryOp` -> `f"({left} {op} {right})"` using `_BINARY_OPS` dict mapping
   - `UnaryOp` -> `f"({op}{operand})"` using `_UNARY_OPS` dict
   - `IntegerLiteral` -> `node["value"]`
   - `SequenceExpr` -> recurse into `node["expr"]`
   - `BinaryPropertyExpr` -> map `And`->`&&`, `Or`->`||`
   - `UnaryPropertyExpr` with `op="Not"` -> `f"(!{expr})"`
   - Default case: raise `UnsupportedConstruct`

3. `extract_source_loc(node: dict) -> SourceLoc`
   - Returns `SourceLoc(file=node.get("source_file_start", "<unknown>"), line=node.get("source_line_start", 0), col=node.get("source_column_start", 0))`

4. `_check_unsupported(node: dict, source_loc: SourceLoc) -> None`
   - Checks node kind against `UNSUPPORTED_KINDS_PHASE1` dict
   - Keys: "SequenceConcat", "SequenceRepetition"
   - Raises `UnsupportedConstruct` with construct_name and source_loc

Define `_BINARY_OPS: dict[str, str]` mapping: BinaryAnd->"&", BinaryOr->"|", BinaryXor->"^", LogicalAnd->"&&", LogicalOr->"||", Equality->"==", Inequality->"!=", LessThan->"<", LessThanEqual->"<=", GreaterThan->">", GreaterThanEqual->">="

Define `_UNARY_OPS: dict[str, str]` mapping: LogicalNot->"!", BitwiseNot->"~", UnaryMinus->"-", UnaryPlus->"+"
</action>
