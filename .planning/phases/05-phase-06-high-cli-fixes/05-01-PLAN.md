<title>HARDEN-06: Extend --property matching to support index and source-line</title>
<read_first>
- src/sva2rtl/cli.py (~line 119-135: --property matching)
- .planning/phases/05-phase-06-high-cli-fixes/05-CONTEXT.md (match priority: label → index → line)
</read_first>
<action>
Replace the current label-only matching logic with three-mode matching:

```python
if property_name is not None:
    # Mode 1: numeric → 1-based index
    if property_name.isdigit():
        idx = int(property_name)
        if 1 <= idx <= len(assertions):
            assertions = [assertions[idx - 1]]
        else:
            raise PropertyNotFound(
                message=f"property index {idx} out of range (1..{len(assertions)})",
                property_name=property_name,
                available=[str(i) for i in range(1, len(assertions) + 1)],
            )
    # Mode 2: @N → source line
    elif property_name.startswith("@") and property_name[1:].isdigit():
        line_num = int(property_name[1:])
        matched = [
            (node, clock, text, label)
            for node, clock, text, label in assertions
            if hasattr(node, 'source_loc') and node.source_loc and node.source_loc.line == line_num
        ]
        if not matched:
            available_lines = sorted(set(
                str(n.source_loc.line) for n, _, _, _ in assertions
                if hasattr(n, 'source_loc') and n.source_loc
            ))
            raise PropertyNotFound(
                message=f"no assertion found at line {line_num}",
                property_name=property_name,
                available=available_lines,
            )
        assertions = matched
    # Mode 3: label name
    else:
        matched = [(node, clock, text, label) for node, clock, text, label in assertions if label == property_name]
        if not matched:
            available_labels = [label for _, _, _, label in assertions if label is not None]
            raise PropertyNotFound(
                message=f"property '{property_name}' not found",
                property_name=property_name,
                available=available_labels,
            )
        assertions = matched
```

Note: `PropertyNotFound` may need its `available` field changed to accept `list[str]` — verify and adapt.
</action>
